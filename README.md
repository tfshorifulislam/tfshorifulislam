## ABOUT

I'm a Full Stack Web Developer passionate about building reliable, scalable, and meaningful digital products.

I enjoy working across the entire development lifecycle — from designing intuitive interfaces to developing backend systems, APIs, authentication, and database architectures.

My primary focus is the JavaScript and TypeScript ecosystem, with a strong interest in backend engineering and modern application architecture.

- Exploring SaaS platforms, real-time applications, and AI integration.
